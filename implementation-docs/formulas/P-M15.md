## 2. Definição Matemática

A equação P-M15 é:

```text
D =

    1.10098229

    - 0.00145899 × X2

    + 0.00000701 × X2²

    - 0.00032770 × AGE
```

Onde:

```text
X2 =

    SKINFOLD_TRICEPS

    + SKINFOLD_ABDOMEN
```

Saída:

```text
outputType:

    BODY_DENSITY
```

A equação utiliza duas dobras cutâneas e idade.

As duas dobras são tríceps e abdômen. A tese define `X2` como a soma das dobras cutâneas tricipital e abdominal.

## 2. Definição Matemática

A equação P-F11 é:

```text
D =
    1.19547130
    - 0.07513507 × LOG10(Y4)
    - 0.00041072 × AGE
```

Onde:

```text
Y4 =
    SKINFOLD_AXILLARY_MID
    + SKINFOLD_SUPRAILIAC
    + SKINFOLD_THIGH
    + SKINFOLD_MEDIAL_CALF
```

Saída:

```text
outputType:
    BODY_DENSITY
```

A equação utiliza o logaritmo na base 10 da soma de quatro dobras cutâneas juntamente com a idade. A combinação de quatro dobras é a configuração `Y4` das equações femininas de Petroski. A forma publicada da equação confirma os coeficientes e a composição das quatro dobras.

```text

    FEMALE → compatível com o sexo documentado

    comparar com a evidência populacional documentada

    NOT_DOCUMENTED

    NOT_DOCUMENTED

modality:
    NOT_DOCUMENTED

    nenhuma regra explícita

    AGE
    + 4 dobras cutâneas

output:
    BODY_DENSITY
```

O motor não deve transformar a média de idade de desenvolvimento em limite de elegibilidade, e a ausência de evidência sobre atleta, nível de treinamento ou modalidade não deve resultar em `INELIGIBLE`.

A P-F11 é a variante feminina logarítmica de quatro dobras de Petroski, utilizando:

```text
Y4 =
    axilar média
    + supra-ilíaca
    + coxa
    + panturrilha medial
```

Além de `Y4`, a equação requer `AGE`. A forma matemática deve permanecer distinta de P-F10 e P-F12, mesmo quando essas variantes compartilham a mesma configuração `Y4` de quatro dobras.

```text
P-F10:
    AGE + BODY_MASS + HEIGHT + Y4

P-F11:
    AGE + Y4

P-F12:
    AGE + Y4 + CIRCUMFERENCE_ABDOMEN
```

P-F10, P-F11 e P-F12 compartilham a configuração `Y4`, mas possuem definições matemáticas distintas e não devem ser fundidas pelo `SuggestionEngine`.

## 2. Definição Matemática

A equação P-M13 é:

```text
D =

    1.10404686
    - 0.00111938 × Z3
    + 0.00000391 × Z3²
    - 0.00027884 × AGE
```

onde:

```text
Z3 =

    SKINFOLD_SUBSCAPULAR
    + SKINFOLD_TRICEPS
    + SKINFOLD_PECTORAL
```

Saída:

```text
outputType:

    BODY_DENSITY
```

A P-M13 utiliza três dobras cutâneas e idade. A publicação científica que reproduz as equações generalizadas masculinas de Petroski apresenta para PM13 exatamente os coeficientes acima e define o termo como a soma das dobras subescapular, tricipital e peitoral.

Unidades das variáveis matemáticas:

```text

    milímetros (mm)

SKINFOLD_TRICEPS:
    milímetros (mm)

SKINFOLD_PECTORAL:
    milímetros (mm)

AGE:
    anos

BODY_DENSITY:
    g/ml
```

As definições de técnica, precisão e faixas plausíveis das medidas permanecem na biblioteca de medições correspondente.
